## 实现要点

1. 在 `src/adapters/hrails.ts` 的 `HRailsClient` 类新增 `listMarkets()` 方法
2. 在 `src/tools/outcomes.ts` 的 `outcomes_check_arbitrage` 后面新增工具
3. 参考已有的 `outcomes_list_events` 写法

### HRailsClient 新增方法

```typescript
async listMarkets() {
  return this.get("/api/v1/markets")
}
```

### 工具模板

```typescript
server.tool(
  "outcomes_list_markets",
  "## 功能：列出所有预测市场\n## 场景：用于浏览全部可用市场、发现交易机会\n## 关键词：预测市场, markets, 市场列表\n## 参数：无\n## 鉴权：需要 HRAILS_API_KEY\n## 风险：READ — 只读查询\n## 返回量：微小 ~3KB\n## 关联：outcomes_list_events → 本工具 → outcomes_get_market 看详情",
  {},
  async () => {
    const client = getHRailsClient()
    if (!client) return toError(new Error("未配置 HRAILS_API_KEY"))
    try {
      const data = await client.listMarkets()
      return toResult(data)
    } catch (e) { return toError(e) }
  }
)
```
