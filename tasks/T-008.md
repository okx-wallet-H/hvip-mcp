# T-008: WebSocket 私有频道（6 个频道）

**难度** ⭐⭐⭐ · **行数** ~120 · **依赖** T-007 的 WebSocket 基础

---

## 概述

对接 OKX Outcomes 的 6 个私有 WebSocket 频道，需要 API Key 登录鉴权。

**WebSocket 端点：** `wss://ws.okx.com:8443/ws/v5/business`

**鉴权方式：** 连接后发送 login 消息，HMAC-SHA256 签名

---

## 频道列表

| # | 频道 | 用途 | 是否需要 login |
|---|------|------|:---:|
| 1 | `pm-order` | 订单状态变更推送 | ✅ |
| 2 | `pm-position` | 持仓变更推送 | ✅ |
| 3 | `pm-user-trade` | 用户成交推送 | ✅ |
| 4 | `pm-balance` | 余额变更推送 | ✅ |
| 5 | `pm-pnl` | 盈亏推送 | ✅ |

---

## 工具规划

复用 T-007 的 `okx_ws_predictions_subscribe` 工具，增加 login 鉴权逻辑。

| 工具名 | 功能 |
|--------|------|
| `okx_ws_predictions_login` | 发送登录鉴权 |
| `okx_ws_predictions_subscribe` | 订阅私有频道（复用，增加 auth 参数） |

---

## 实现要求

1. 在 T-007 基础上扩展
2. login 消息签名：`sign(timestamp + "GET" + "/users/self/verify" + "", secret)`
3. login 消息体：
```json
{
  "op": "login",
  "args": [{"apiKey": "...", "passphrase": "...", "timestamp": "...", "sign": "..."}]
}
```
4. 5 个私有频道对应 5 个事件类型

## 验收标准

- [ ] 能成功 login 并订阅私有频道
- [ ] 断线后自动重连并重新 login
- [ ] 事件区分频道来源
- [ ] API Key 未配置时给出明确错误提示
- [ ] 8 字段描述完整
