# T-004：Outcomes 持仓 & 账户（6 端點）

> 难度 ⭐⭐ · 部分需要 EIP-712 · 约 160 行代码

## API 端点

Base: `https://www.okx.com`

| # | 端点 | 方法 | 说明 | 鉴权 |
|---|------|------|------|:--:|
| 1 | `/api/v5/predictions/positions` | GET | 持仓查询 | API Key |
| 2 | `/api/v5/predictions/positions/split` | POST | xp → YES + NO | EIP-712 |
| 3 | `/api/v5/predictions/positions/merge` | POST | YES + NO → xp | EIP-712 |
| 4 | `/api/v5/predictions/positions/redeem` | POST | 赎回赢家代币 | EIP-712 |
| 5 | `/api/v5/predictions/balance` | GET | xp 余额 | API Key |
| 6 | `/api/v5/predictions/trades` | GET | 成交记录 | API Key |

## 工具规划

| 工具名 | 端点 | 参数 | 鉴权 |
|--------|------|------|:--:|
| `okx_predictions_positions` | GET /positions | marketId?, status? | 🔐 |
| `okx_predictions_split` | POST /positions/split | amount | 🔐 |
| `okx_predictions_merge` | POST /positions/merge | amount | 🔐 |
| `okx_predictions_redeem` | POST /positions/redeem | assetId? | 🔐 |
| `okx_predictions_balance` | GET /balance | — | 🔐 |
| `okx_predictions_trades` | GET /trades | marketId?, limit? | 🔐 |

## 实现要点

1. **split/merge** 是预测市场特有的资金操作，用来在 xp（现金）和 YES/NO 代币之间转换
2. **redeem** 在事件结算后调用，把获胜的 YES/NO 代币按 1:1 换回 xp
3. EIP-712 签名需求同 T-003
4. 余额返回的是 **xp**（预测市场的计价单位），不是 USDT
