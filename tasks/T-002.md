# T-002：Outcomes 市场数据（3 端點）

> 难度 ⭐ · 公开接口 · 无需签名 · 约 70 行代码

## API 端点

Base: `https://www.okx.com` · 鉴权: **无需**

| # | 端点 | 说明 |
|---|------|------|
| 1 | `GET /api/v5/market/ticker?instId={yesAssetId}` | 行情报价 |
| 2 | `GET /api/v5/market/candles?instId={yesAssetId}` | K 线数据 |
| 3 | `GET /api/v5/market/pm-books?instId={yesAssetId}&sz=400` | 深度（最多400档） |

## 工具规划

| 工具名 | 端点 | 参数 |
|--------|------|------|
| `okx_predictions_ticker` | /market/ticker | instId |
| `okx_predictions_candles` | /market/candles | instId, bar?, limit? |
| `okx_predictions_orderbook` | /market/pm-books | instId, sz? |

## 实现要点

1. 复用 **现有的** `publicApi.getTicker()` / `publicApi.getCandles()` 直接传 `instId` — 无需新建适配器方法
2. 对 `pm-books` 需要在 `publicApi` 新增一个方法
3. 描述必须用 8 字段模板

### 新增适配器方法

```typescript
// 在 publicApi 对象内追加：
getPredictionsOrderbook: (instId: string, sz?: number) =>
  request<unknown>("GET", "/api/v5/market/pm-books", { params: { instId, sz: sz ?? 400 } }),
```

### 关键提醒

- `instId` 是预测市场的 **yesAssetId**，不是 marketId
- Ticker/Candles 直接复用 `publicApi.getTicker(instId)` 和 `publicApi.getCandles(instId, bar, limit)`
