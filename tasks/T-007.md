# T-007: WebSocket 公共行情频道（5 个频道）

**难度** ⭐⭐ · **行数** ~150 · **依赖** `ws` 包

---

## 概述

对接 OKX Outcomes 的 5 个公共 WebSocket 频道，实现实时行情订阅。

**WebSocket 端点：** `wss://ws.okx.com:8443/ws/v5/business`

---

## 频道列表

| # | 频道 | 用途 | 订阅参数 |
|---|------|------|---------|
| 1 | `prediction-market-prices` | 实时预测市场成交价 | `[{"instId": "<asset_id>"}]` |
| 2 | `pm-books` | 实时深度数据 | `[{"instId": "<asset_id>"}]` |
| 3 | `pm-trades` | 实时成交记录 | `[{"instId": "<asset_id>"}]` |
| 4 | `pm-tickers` | 实时行情（24h 数据） | `[{"instId": "<asset_id>"}]` |
| 5 | `pm-event-status` | 事件状态变更通知 | `[{"instId": "event-<event_id>"}]` |

---

## 工具规划

| 工具名 | 功能 |
|--------|------|
| `okx_ws_predictions_subscribe` | 订阅一个或多个频道 |
| `okx_ws_predictions_unsubscribe` | 取消订阅 |
| `okx_ws_predictions_events` | 拉取缓冲区内的事件 |
| `okx_ws_predictions_status` | 查看 WebSocket 连接状态 |

---

## 实现要求

1. 在 `src/adapters/` 下新建 `ws-predictions.ts`，封装 WebSocket 连接管理
2. 自动重连、心跳保活（ping/pong）
3. 事件缓冲区（内存队列），防止 Agent 处理不过来
4. 工具代码写在 `src/tools/` 下新建 `ws-predictions.ts`
5. 8 字段描述模板
6. `npm run build` 通过

## 验收标准

- [ ] `npm run build` 通过
- [ ] 5 个频道均可订阅
- [ ] 支持多个 instId 同时订阅
- [ ] 自动重连（断线后重试 3 次）
- [ ] 8 字段描述完整
- [ ] `toResult()` / `toError()` 错误处理
