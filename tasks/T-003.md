# T-003：Outcomes 订单管理（6 端點）

> 难度 ⭐⭐ · 需要 EIP-712 签名 · 约 180 行代码

## ⚠️ 前置知识

Outcomes 订单需要 **EIP-712 签名**，不是标准 OKX API Key 签名。

签名流程：
1. 用 OKX API Key 发起请求获取待签名数据
2. 用 Agent 私钥对数据做 EIP-712 签名
3. 把签名附在请求中发送

## API 端点

Base: `https://www.okx.com` · 鉴权: **OKX API Key + EIP-712 签名**

| # | 端点 | 方法 | 说明 |
|---|------|------|------|
| 1 | `/api/v5/predictions/orders` | POST | 下单 |
| 2 | `/api/v5/predictions/orders/cancel` | POST | 撤单 |
| 3 | `/api/v5/predictions/orders/cancel-all` | POST | 全部撤单 |
| 4 | `/api/v5/predictions/heartbeat` | POST | 心跳保活 |
| 5 | `/api/v5/predictions/orders/{orderId}` | GET | 订单详情 |
| 6 | `/api/v5/predictions/orders` | GET | 订单列表 |

## 实现要点

1. **EIP-712 签名**：需 `@metamask/eth-sig-util` 或 `viem` 或手动实现。如果未配置 Agent 私钥，返回错误提示。
2. 在 `src/adapters/okx.ts` 的 `privateApi` 下新增 4 个 POST 方法
3. 下单参数：`outcome=yes/no`、`side=buy/sell`、`marketId`、`size`（合约张数）、`price`（限价单必填）
4. 心跳保活用于防止断线自动撤单
